# 图片批量下载助手

这是一个无需构建的 Chrome Manifest V3 扩展。在 ChatGPT 图片页面中选择图片，点击下载后再指定目录。本项目由个人独立开发，并非 OpenAI 官方产品。

## 支持的页面

- **生成结果页**：读取中央主图右侧的当前图片组。
- **全屏图片查看器**：读取中央主图左侧的当前图片系列。

图片消息下方的批量下载图标可直接打开当前页的选择面板。生成结果页的图标会加入图片消息的操作行；找不到操作行时放在图片组下方。全屏查看器的图标位于页面右上角工具栏、缩放按钮左侧。Chrome 工具栏中的扩展图标用于打开语言与赞赏设置面板。

对话操作行中的图标使用与页面接近的线框样式；图标、选择面板和大图预览会跟随 ChatGPT 的亮色或暗色主题。预览以整页画布显示图片，上一张与下一张按钮位于画布左右两侧，底部显示序号和勾选框。

点击 Chrome 工具栏中的扩展图标，在弹出面板里选择“中文”或“English”即可切换界面语言。默认是中文，选择会保存在浏览器本地；切换会同步到已打开的图片选择面板，不会清空当前勾选、扫描提示或下载进度。弹出面板还显示联系邮箱 xinyiu777@gmail.com，点击可打开邮件应用。“赞赏码”可展开，切换支付宝与微信；点击二维码可在新标签页查看原图。

## 安装与使用

1. 在 Chrome 打开 chrome://extensions，启用“开发者模式”，选择“加载已解压的扩展程序”，选中本目录。更新扩展文件后，在扩展管理页点击“重新加载”，再刷新 ChatGPT 页面。
2. 打开上述任一图片页面，点击图片消息下方或全屏查看器右上角工具栏的批量下载图标。扩展直接读取当前图片组并展示缩略图与序号，不滚动网页的缩略图列表，也不切换主图。鼠标滚轮可滚动面板内的图片列表，不会滚动后方页面。点击卡片的文字或空白区域可切换勾选；点击卡片最右侧缩略图可打开大图预览、切换前后图片，并在预览中勾选。默认全选，也可以逐张取消；“全选”“全不选”位于面板右上方。
3. 点击面板右下角的“下载已选”，Chrome 会先让你选择保存目录，然后开始下载。扩展最多同时保存 3 张，显示逐张进度和成功数量。失败项可再次点击重试，沿用本批次目录；同一批次已成功的图片不会重复保存。遇到现有文件名会添加序号，不覆盖已有文件。

## 说明

- 扩展根据页面主图和左右缩略图识别当前图片组，不会暗中滚动或切换页面。扫描时会容忍列表末端的正常留白。如果仍无法确认网页是否已渲染完整列表，但已读取到可下载的图片，面板会展示这些图片；核对列表并勾选“已核对”后，可只下载其中选中的图片，也可以点击“重试”。若有图片无法确认大图地址，下载仍会暂停并提示重试。
- 扩展请求页面显示的图片地址并保存收到的图片字节，不转换或压缩。它不与 ChatGPT 自带单张下载文件做原图比对，因此不保证两者字节一致。
- 支持 PNG、JPEG、WebP、GIF、AVIF、BMP、TIFF；单张最大 24 MiB。资源地址失效或目录写入失败时，面板会显示对应错误。
- 目录句柄只保留在当前图片组的下载过程中。切换图片组或刷新页面后，下次点击下载会重新选择目录。

运行 node --test tests/*.cjs 可以检查两种缩略图布局、无滚动读取、列表尾部留白与不完整列表的处理、缺失或低分辨率来源的拦截、大图预览、中英文切换及偏好保存、赞赏码资源、选择与保存数量、目录选择取消与失败重试和非覆盖写入。本地模拟测试不能代替真实 ChatGPT 页面上的人工试用。

## 文件

- manifest.json：扩展清单。
- gallery.js：当前图片组定位与缩略图遍历。
- image-io.js：图片获取及目录写入。
- content.js、panel.css：页面按钮、选择面板和保存流程。
- popup.html、popup.css、popup.js：工具栏弹出面板、语言设置、联系邮箱和赞赏码。
- assets/：支付宝与微信赞赏码原图。
- icons/：扩展和商店使用的图标。
- background.js：受限域名的图片请求。
- tests/：本地模拟测试。
